Design System Tradegrape

Référence unique pour l'implémentation React (Next.js + Supabase). Chaque composant est présenté dans toutes ses variantes et tous ses états — repos, survol, focus clavier, désactivé, erreur — avec ses props attendues en commentaire dans le code source de cette page. Les classes .is-hover et .is-focus figent les états dynamiques à des fins de documentation.

Compositions

Les composants assemblés en situation réelle. C'est ici que se juge la direction : effets sur les surfaces marketing, sobriété totale sur les surfaces de données.

Progress & Jauges

Le cœur du journal : chaque règle de trading est une jauge. Le ton bascule automatiquement (brand → warn → danger) selon les seuils, et le statut est toujours doublé d'une icône + d'un libellé — la couleur seule ne porte jamais l'information.
